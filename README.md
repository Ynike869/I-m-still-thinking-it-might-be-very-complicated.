# 個人酒館助手

這是自用的 SillyTavern UI 擴充程式，採模組化方式逐步整合個人工具。

## 目前功能

- 聊天輸入區入口，可從酒館聊天介面開啟助手。
- 擴充設定區入口。
- 可選擇開啟／關閉的懸浮球，支援拖曳與記住位置。
- 助手設定頁可管理功能模組的顯示狀態。
- 「畫師串儲存庫」模組入口。
- 畫師串儲存庫正在整合使用者原有的 NAI 畫師串庫 V7.3 腳本，保留原腳本介面與資料處理邏輯，並新增助手啟動入口。

## 畫師串儲存庫注意事項

- 原始腳本來源：使用者提供的「NAI畫師串庫 V7.3｜修正懸浮球誤觸」。
- 模組檔案：`modules/artist-prompt-library.js`。
- 目前移植以保留原腳本為目標；尚未在使用者的實際 SillyTavern 環境完成完整相容性測試。
- 原腳本包含 JS-Slash-Runner／酒館環境依賴，若部分功能未正常運作，需再逐項處理相容性。
- 請先備份原有提示詞資料，再測試更新版本。

## 安裝／更新測試

在 SillyTavern 的「擴充」→「安裝擴充」中，輸入本倉庫的 Git URL。安裝或更新後，重新整理酒館頁面並啟用「個人酒館助手」。
